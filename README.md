# Wicked Games Music Player

This is a static music player. Open `index.html` directly, or publish the repository with GitHub Pages.

## Run locally

From this folder, start a local web server:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository, open **Settings > Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the branch containing `index.html` and the `/ (root)` folder.
5. Save, then wait for GitHub to publish the site.
